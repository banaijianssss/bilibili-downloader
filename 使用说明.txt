bilibili下载器 · Windows 版

这个压缩包就是给 Windows 10 / 11 用的。解压后双击「启动.bat」。

使用前
1. 安装 Python 3.11 或更高版本。
   https://www.python.org/downloads/windows/
   安装时必须勾选 Add python.exe to PATH。
2. 安装 FFmpeg，否则最高画质无法封装成 MP4。
   打开 PowerShell 执行：winget install Gyan.FFmpeg
   或把 ffmpeg.exe 放在本目录，启动脚本会自动加进 PATH。

第一次双击
脚本会创建 .venv、安装依赖，然后打开 http://127.0.0.1:8787
关闭黑色窗口即停止。下载文件默认在系统「下载」目录。
下载任务会保存在 data\jobs.db：关掉再开仍可看到排队/中断任务，失败可点重试。

新能力简述
- 批量分 P：详情页可勾选或「全部下载」
- 队列限并发 2，支持取消与重试；进度可用 SSE 实时刷新
- 可选下载字幕与封面
- 扫码登录后若有 refresh_token，会尝试自动续期；失效时提示「需重新扫码」

1080P+、4K、HDR 需要大会员。在页面「账号与画质」扫码或粘贴 SESSDATA，只保存在本机 data\settings.json。

请只用于个人学习，以及你已获授权保存的内容。
